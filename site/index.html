Daily flow

日常任务该有的能力，保持轻量。

从快速记下一件事，到按日期推进、完成、恢复与短暂撤销，都走同一份 Host 权威账本。

01

六个清晰视图

今天、收件箱、未来、已完成、工作、个人；今天同时收纳过期任务并按时间排序。

02

完整任务细节

标题、备注、清单、优先级、日期、时间、提醒，以及每天、每周、每月重复。

03

安全撤销

完成、删除和改期后提供短暂撤销；遇到另一个标签页的冲突时拒绝覆盖。

04

运行期间提醒

支持错过提醒与稍后提醒；不承诺 DSH 关闭或系统休眠时仍能准时通知。

05

Host 可靠存储

revision、幂等请求、SSE、原子 rename、损坏文件隔离与恢复前备份。

06

键盘与无障碍

N 快速新建、/ 搜索、Enter 打开、Space 完成，并提供焦点、状态与语义区域。

Agent tools

直接告诉 Agent，你想怎么安排。

创建、查询、修改和完成都调用与 UI 相同的本机 Host 服务。同名任务必须先消歧，删除必须明确确认。

明天上午十点提醒我检查发布说明，提前十分钟。

✓已创建“检查发布说明”，安排在明天 10:00，提前 10 分钟提醒。

i找到两条同名任务。我列出了 task id，请选择要完成的一条。

One color system

浅色、深色、社区皮肤，始终与 DSH 同色。

正式插件不复制原型固定颜色，不写独立明暗主题，也不修改全局主题 token。

Local by default

任务默认留在本机。

任务写入 $DSH_HOME/task-planner/tasks-v1.json。没有默认云同步、分析、遥测或追踪。JSON 导出由你自行保管。

FAQ

常见问题

会修改 DSH 源码吗？

不会。插件通过 Cordis Bundle 与官方 Client Slot 接入。

DSH 关闭后提醒还会准时出现吗？

不会做这种承诺。提醒依赖 DSH Web GUI 与浏览器运行；恢复后可以在设定范围内显示错过提醒。

数据会上传云端吗？

默认不会。任务保存在本机，站点与插件都不默认接入统计或追踪脚本。

为什么同名任务需要选择 id？

这是 Agent 工具的安全约束，避免自然语言修改或删除错误任务。
