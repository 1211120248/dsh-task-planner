# Security policy

Please do not disclose vulnerabilities through public issues. Use GitHub's private vulnerability reporting for [dsh-task-planner](https://github.com/linxin666/dsh-task-planner/security/advisories/new).

Include the affected version, impact, reproduction steps, and a minimal sanitized example. Do not include real task exports, local paths, API keys, tokens, or private screenshots.

The latest released minor version receives security fixes.
